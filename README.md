# Annotator

This repository hosts the generated website, approved app downloads, release
notes, public issues and Homebrew casks. It does not contain the private
application or website authoring source.

Website: https://dorlugasigal.github.io/annotator/ (deployment is not enabled yet).

Once a verified cask is published:

```sh
brew tap dorlugasigal/annotator https://github.com/dorlugasigal/annotator
brew install --cask dorlugasigal/annotator/annotator
```

There is no app release or installable cask yet. Do not use the command as
proof that a download is currently available.

Read each release's known limits. Use fictional content when reproducing a
problem. Never include credentials, private desktop screenshots or unrelated
documents in a public issue.

If macOS blocks an installation, report the exact message. Do not disable
security checks or remove quarantine to force the app open.
