# Getting help

- [Help](https://getannotator.app/docs/) covers first steps, shortcuts,
  permissions, screen sharing and saving boards, on Mac and Windows.
- The [release notes](https://github.com/dorlugasigal/annotator/releases) list
  what changed and the known limits of each version.
- [Ask a question](https://github.com/dorlugasigal/annotator/issues/new?template=question.yml)
  if Help doesn't answer it.
- [Report a problem](https://github.com/dorlugasigal/annotator/issues/new?template=bug-report.yml)
  if something doesn't work, or
  [suggest a feature](https://github.com/dorlugasigal/annotator/issues/new?template=feedback.yml).

Before you report, update to the latest version. In Annotator, Settings >
About > Copy support info gathers app and system details without drawings or
screenshots. Review it, then paste it into your report. Issues are public, so
use made-up data.

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening an
issue.
