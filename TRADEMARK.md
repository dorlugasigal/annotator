# Name and icon

The Apache License 2.0 covers Annotator's code. It does not cover the name
"Annotator" as used for this app, the A mark, or the app icon (section 6 of
the licence). They identify the official builds.

You may:

- build, change and use the code for yourself or your organization;
- say that your project is based on Annotator, or link to this repository;
- show the name and icon when you write or talk about Annotator.

If you distribute a modified build, give it its own name and its own icon, so
people can tell it apart from the official app. Don't publish a build under
the Annotator name or icon in the Microsoft Store, Homebrew, winget or any
other store or package manager. Don't suggest that the project endorses your
build.

Ask in an issue if you aren't sure.
