# Contributing

Annotator's source code is private, so this repository doesn't take pull
requests. You can still help:

- Try the latest alpha and [report problems](https://github.com/dorlugasigal/annotator/issues/new?template=bug-report.yml) you find.
- [Share feedback](https://github.com/dorlugasigal/annotator/issues/new?template=feedback.yml) about what felt useful, confusing or missing.
- Tell us when a known limit in the [release notes](https://github.com/dorlugasigal/annotator/releases) gets in the way of your work.

A good report names the Annotator version and build, your macOS version and
Mac model, your displays if it's about drawing or zoom, and the exact steps.
Keep it safe to publish: made-up data only, no credentials and no private
screenshots.
