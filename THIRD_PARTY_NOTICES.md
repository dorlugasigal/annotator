## Windows app icons

The Windows app replaces the Mac's SF Symbols with Lucide icons (decision D-6),
from the npm package `lucide-static` 1.59.0. `apps/windows/src/Annotator.App/Assets/icon-map.json`
maps each SF Symbol name to a Lucide icon, and `tools/windows/update-lucide-icons.mjs`
converts only the mapped icons into path data in
`apps/windows/src/Annotator.App/Icons/LucideIcons.g.cs`; no SVG files or SVG
interpreter ship. The complete ISC license and notices for Feather-derived MIT
icons are retained in `apps/windows/src/Annotator.App/Assets/Lucide-LICENSE.txt`
and copied next to the Windows app. A few symbols with no matching Lucide icon use
original Annotator drawings from the map's `glyphs` section; they are not Lucide
or SF Symbols artwork.

## Windows edition Unicode character data

Swift compares strings by canonical equivalence and maps case with the full
Unicode mappings; .NET with invariant globalization does neither. The Windows
edition's `apps/windows/src/Annotator.Core/Text/SwiftUnicodeData.g.cs` holds the
canonical decompositions, combining classes, primary composites and full case
mappings it needs, generated by `tools/windows/generate-unicode-tables.py` from
the Unicode Character Database 16.0.0 as shipped in Python's `unicodedata`
module. Unicode data is used under the Unicode License V3, retained in
`apps/windows/src/Annotator.Core/Text/Unicode-LICENSE.txt`; the Windows app must
ship that file. The owner approved this use on 2026-10-19
(`docs/provenance/components.json`).

## Rough.js native geometry port

`apps/macos/Sources/PresentationRendering/RoughGeometry.swift` adapts Rough.js's seeded
generator, paired cubic line strokes, cubic perturbation and sampled ellipse
construction. Copyright (c) 2019 Preet Shihn, MIT. The complete notice is
retained in `apps/macos/Annotator/RoughJS-LICENSE.txt` and included in the app.
Reference coordinates are generated using Rough.js 4.6.6. No JavaScript runtime
is embedded in the native application.
The native ellipse adaptation subdivides long closing overlap arcs and keeps
the terminal tangent local to prevent interior-crossing chords at high roughness.
Seeded displacement and paired strokes are retained.
`apps/windows/src/Annotator.Core/Geometry/RoughGeometry.cs` is a C# port of the
Swift adaptation for the Windows edition, under the same notice; the Windows
app must ship the same license file.
