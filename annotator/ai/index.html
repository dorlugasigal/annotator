Made for macOS

AI CONTROL

Let your AI use Annotator.

The skill tells an AI assistant how to click the tools, draw and edit in the Mac app. Your AI app must already have computer-use tools. This download does not add those tools or grant macOS permissions.

Download the AI skill

Unzip the download. You will get an annotator folder with a SKILL.md file inside. You can also save this folder from Annotator using Save AI skill... in Help or Settings.

Install in Copilot CLI

Move the annotator folder into ~/.copilot/skills/. Create the skills folder if it does not exist.

Or, in Copilot CLI, type /skills add /path/to/annotator. Replace the path with the folder you unzipped. Then run /skills reload and /skills info annotator to check it.

Install in Claude Code

Move the annotator folder into ~/.claude/skills/. Start a new session. You can then ask Claude Code to use the /annotator skill.

Use another AI app

Follow that app's instructions for adding a skill folder. An AI app that cannot control your Mac will not gain that ability from this skill.

Try it

Open Annotator and the thing you want to explain. Ask your AI assistant:

Use Annotator to circle the wrong date and add “Check this date”.

The assistant should make the changes in the app and check the result. It should keep your existing work and ask before sharing or deleting anything outside your request.

Your AI app may send screenshots to its model provider. Check its privacy settings before using private information. Annotator's usual app permissions still apply. All tools are free.
