What the film shows

Sketch an API and cache using Smart Draw. Place labels inside their shapes. Open the resizable shape library, choose a person and database, then style and connect them. The dashed curve marks a cache miss. Highlight the API, move an annotation and Undo. In a separate browser window, native Blur softens a sample contact card.

The current app was recorded at the display’s native pixel resolution. Camera motion follows recorded cursor positions, with the tool choices kept in frame and a short motion trail during camera moves. The footage is scripted and sped up, not a human recording. The browser and notes contain fictional data. Only controlled windows are captured; no unrelated desktop content is included. Blur is produced by Annotator, not video editing, and is not secure redaction.

A few things to know

About the preview.

Can I download Annotator today?

Not publicly yet. The app is in private development. The examples on this page demonstrate features; they are not a public download.

Do I need to pay for any features?

No. All tools are free. Buying me a beer is an optional thank-you, not a purchase or a requirement to use Annotator.

Is this a screen recorder?

No video is recorded. macOS calls the permission “Screen Recording” because live zoom and effects read screen pixels. Images are saved only through explicit image export.

What still needs work?

We need more tests on different Macs, screens and calling apps. Public distribution and signed updates are not ready yet. The help page explains what works now.
